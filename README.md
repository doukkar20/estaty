# Estaty / RAFAIMMOBILIER

Multi-vendor real estate property listings built with Laravel 9 and PHP 8.2.
Includes the existing RAFAIMMOBILIER branding, French/Arabic interfaces, property
search, and customer, agent, vendor, and administrator areas.

See [DEPLOYMENT.md](DEPLOYMENT.md) for Docker/Railway hosting instructions.
GitHub Pages cannot execute this application's PHP or MySQL backend.

This private repository preserves the application's original author attribution.
Local secrets, the live database, and runtime files are excluded from source.
